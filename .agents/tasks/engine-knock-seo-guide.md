## ۳. نحوه درج مقاله در دیتابیس

### روش ۱: استفاده از API (توصیه می‌شود)

فرض می‌کنیم backend شما روی `http://localhost:5000` در حال اجراست.

```bash
curl -X POST http://localhost:5000/api/articles \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_AUTH_TOKEN" \
  -d @.agents/tasks/engine-knock-article.json
```

**نکته**: فایل JSON آماده است و می‌توانید مستقیماً از آن استفاده کنید.

## ۶. Schema Markup (پیشنهادی)

برای بهبود SEO، پیشنهاد می‌شود Schema زیر را اضافه کنید:

```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "رفع ناک ماشین: علل، تشخیص و راه‌حل‌های کامل + نقش ECU",
  "description": "راهنمای جامع رفع ناک ماشین؛ بررسی کامل علت‌های ناک موتور...",
  "author": {
    "@type": "Organization",
    "name": "نام سایت شما"
  },
  "datePublished": "2024-01-XX",
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "https://yourdomain.com/wiki/rafeh-nak-mashin"
  }
}
```

و برای بخش FAQ:

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "آیا ناک خفیف موتور خطرناک است؟",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "ناک خفیف و گذرا در برخی شرایط طبیعی است..."
      }
    }
    // بقیه سوالات
  ]
}
```
